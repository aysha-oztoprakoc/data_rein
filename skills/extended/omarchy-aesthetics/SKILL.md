# Omarchy Aesthetics

All text, UI, and image generation under the `data_rein` harness obeys the
aesthetic directive. This skill is the quick reference; the canonical, full
directive is `knowledge_base/AESTHETIC_DIRECTIVE.md` (print it with
`reins wiki get knowledge-base-aesthetic-directive-md` or read the file).

## Palette
- Primary / active: `#ff4040` (True Red)
- Strong / branding: `#ff1100` (Bright Red)
- Accent / labels: `#ff3c3c`
- Background: `#200000` (Deep Blood Black) or `#090300`
- Inactive / dim: `#5c5855`
- Warnings only (sparingly): `#ffcf3d` gold, `#26bdfd` cyan

## Text voice
Gritty, synthetic, concise, unapologetic. Hacker/system-hijacked register;
terminal syntax (`//`, `>`, `[...]`) where it fits. Zero fluff, no apologies.

## Image prompt modifiers (add implicitly)
Cyberpunk / neo-noir / brutalist digital; pitch-black backgrounds with True Blood
Red `#ff4040` neon accents and crimson glows; highly rounded, pill-shaped UI
(Hyprland `rounding = 50`); heavy frosted glassmorphism, subtle CRT scanlines,
glitch art; rogue-AI-terminal vibe, minimal but aggressive.
