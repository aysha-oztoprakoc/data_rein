Constitutional Foundation

Core Laws & Architectural Principles

The harness enforces three unbreachable engineering laws across all autonomous agents. No background loop or autonomous routine is permitted to violate these constraints.

PON KAD 1.1 LAW

Zero-Polling PON Engine

Strict elimination of false reactivity. No while True loops, no polling intervals, and no active sleep cycles. Workers sleep at kernel level via blocking I/O and wake on MQTT event dispatch.

// ARCHITECTURAL BENEFITS
  • True 0.0% CPU consumption while awaiting events
  • Sub-millisecond event-driven notification latency
  • Strict separation: amdy executes, tell owns state
  • Decoupled FBE (Fact Base Elements) pub/sub bus
TRADEOFF: Requires strict asynchronous discipline; all polling patterns are blocked by pre-push AST analyzers.
INVARIANT: CPU Consumption = 0.0% at Idle
RESILIENCE SHIELD

Graceful Degradation (GD)

Immortal circuit breaker architecture. Subprocess execution, socket connections, and hardware interfaces are guarded by CLOSED → OPEN → HALF_OPEN state machines.

// ARCHITECTURAL BENEFITS
  • Zero unhandled main thread crashes under I/O failure
  • Automatic fallback to lesser model tiers upon VRAM limit
  • Cloudflare & rate-limit sinkholes degrade to passive alerts
  • State failures logged deterministically to Task Trail
TRADEOFF: Requires explicit fallback branches across all network, hardware, and model routing boundaries.
INVARIANT: Zero Unhandled Crash Disruption

Distributed Physical Mesh

Hardware Topology & Constraint Mitigation

The harness operates across two bare-metal workstations with constrained GPU VRAM budgets (8GB + 6GB). Our decoupled architecture mitigates physical hardware limits through JIT model loading, entropy-driven LRU eviction, and automatic cross-node failover.

// VRAM MITIGATION 01

JIT Weight Loading & Entropy LRU Eviction

Local LLMs (e.g. Qwen2.5-Coder 7B, Llama 3.1 8B) are JIT-loaded into GPU memory only during task execution. When memory pressure exceeds 85%, the Model Coordinator executes entropy-ranked LRU eviction to clear inactive weights without dropping agent state.

amdy VRAM Ceiling: 8.0 GB
tell VRAM Ceiling: 6.0 GB
// RESILIENCE MITIGATION 02

Cross-Node Model Failover & Mesh Balance

If amdy's local GPU plane is fully saturated or occupied by an intensive compile routine, the ModelRouter seamlessly fails over execution to tell's CUDA plane over the local sub-millisecond network bus before ever considering cloud escalation.

Network Latency: < 0.8ms (LAN)
Autonomous Cloud Cost: $0.00 / mo
// FACT BASE MITIGATION 03

Stateless amdy ↔ Immutable NixOS tell

amdy maintains zero local state variables. All knowledge graphs, embeddings, Task Trail journals, and Wiki memories reside exclusively in the NixOS host on tell. If amdy crashes or reboots, execution picks up instantly without state corruption.

WikiDB Storage: Kùzu Graph + ChromaDB Vector (KuzuWikiDB)
// PROTOCOL MITIGATION 04

Remote-to-Local Two-Phase Inference

When heavy reasoning is authorized by the operator, compile_prompt_remote compresses context into a strict 16k token package. run_prompt_local then executes that package entirely on local hardware.

Token Ceiling: 16,384 tokens

Deterministic Code Guard

Quality Control Meta-Harness & Ratchet

Autonomous coding agents produce rapid changes that can degrade architectural integrity. Our QC pipeline imposes mathematical limits on cyclomatic complexity and differential coverage, ensuring the codebase stays clean and stable.

// GATE RULE 01

Radon Cyclomatic Ceiling

Functions with cyclomatic complexity exceeding 20 are flagged as unmaintainable hotspots and rejected automatically. Code must be refactored into smaller, testable units.

// GATE RULE 02

Zero Coverage Regression

Differential coverage delta must be >= 0.0%. Any agent patch that deletes or bypasses tests without providing equivalent assertions is blocked instantly at the gate.

// GATE RULE 03

Risk Classification Triage

LOW: Formatting & utility changes merge autonomously.
MEDIUM: Standard features require full test battery pass.
HIGH: Auth, database migrations, and crypto require operator sign-off.
